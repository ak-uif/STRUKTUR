# STRUKTUR 🛋️✨
> Bakının ilk süni intellekt dəstəkli "Gördüyünü Al" (Shop the Look) interyer dizayn və yerli mebel stok platforması.

STRUKTUR — istifadəçilərə boş otaqlarının şəklini yükləyərək saniyələr içində 4K keyfiyyətində 3D dizayn əldə etməyə və həmin otaqdakı mebelləri birbaşa yerli mağazalardan seçib səbətə ataraq sifariş etməyə imkan verən innovativ MVP layihəsidir.

---

## 🚀 Əsas Xüsusiyyətlər

- **AI Otaq Transformasiyası:** Boş otaq şəklini yükləyin, 3 saniyəlik simulyasiya ilə mükəmməl 4K dizayn olunmuş otağa çevrilməsini izləyin.
- **"Gördüyünü Al" (Shop the Look) Hotspotlar:** Dizayn olunmuş otaq şəklindəki mebellərin (divan, TV, masa və s.) üzərindəki interaktiv nöqtələrə klikləyərək məhsul adını, qiymətini və satıcı mağazanı görün.
- **Dinamik Səbət Sistemi:** Hotspotlardan seçilən məhsulları səbətə əlavə edin, ümumi məbləği hesablayın və sifarişi rəsmiləşdirin.
- **Freemium & Limit İdarəetməsi:** İlk render pulsuzdur, növbəti cəhdlərdə istifadəçini sərfəli paketlərə yönəldən Paywall Modal sistemi.
- **B2B VIP+ Analitika Paneli:** Mebel və dekorasiya mağazaları üçün real vaxt axtarış, trend proqnozu və bazar indeksi statistikaları.
- **Təhlükəsiz B2B Giriş/Qeydiyyat:** Mağazalar üçün xüsusi autentifikasiya (`mebel` / `mebel123`) və VÖEN əsaslı qeydiyyat simulyasiyası.
